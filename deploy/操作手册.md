## 一、系统是做什么的？

简单说，本系统就是公司的一本"电子台账"，用来记录：

- **客户下了什么订单**（订单、订单明细）
- **货收到了多少**（入库）
- **货发出去了多少**（出库）
- **还剩多少没发**（系统自动算，不用您操心）

系统会自动帮您算数量、算金额、算返镀率，还能导出表格和打印。

## 二、使用前的准备

1. 一台能上网的电脑，使用 **Chrome（谷歌浏览器）或 Edge 浏览器**（其他浏览器可能显示不正常）。
2. 向管理员询问两个信息：
   - **系统的网址**（在浏览器地址栏输入即可打开）
   - **您的账号和初始密码**（新员工由管理员开设账号）
3. 请勿在公共电脑上勾选"记住密码"。

## 三、登录、退出和修改密码

### 1. 登录

1. 打开浏览器，输入系统网址，回车。
2. 在登录页面输入：
   - **账号**（您的工号）
   - **密码**
3. 点击 **【登录】** 按钮。

> 如果提示密码错误，请先确认大小写没有输错，再联系管理员。

### 2. 退出

点击页面右上方您姓名旁边的 **小人图标**，在弹出的菜单中选择 **"退出登录"**。
每天下班前建议退出一次。

### 3. 修改密码（建议拿到账号后第一时间修改）

1. 点击右上方 **小人图标** → **"修改密码"**。
2. 依次填写：旧密码、新密码、重复一遍新密码。
3. 点击 **【确定】**。
4. **注意：修改密码成功后系统会自动退出，需要用新密码重新登录。**

### 4. 完善个人信息

点击右上方 **小人图标** → **"完善个人信息"，可以修改自己的用户名（显示在页面顶部的名字）。

## 四、页面总览

登录后，页面分为三个区域：

```
┌─────────────────────────────────────────────┐
│  顶部：公司名称          右上角：您的名字 👤  │
├────────┬────────────────────────────────────┤
│ 左侧   │                                    │
│ 菜单   │          主要工作区域               │
│ 栏     │    （表格、表单都在这里显示）        │
└────────┴────────────────────────────────────┘
```

左侧菜单从上到下依次是：

| 菜单 | 作用 |
|---|---|
| **首页** | 看统计报表（入库、订单、返修情况） |
| **订单管理** | 建立一张新订单（订单的"总单"） |
| **订单明细** | 录入订单里具体的每个部件、数量、价格 |
| **入库管理** | 记录收到客户送来的货 |
| **出库管理** | 记录发给客户的货 |
| **客户公司** | 维护客户名单、员工账号、权限 |
| **字典管理** | 维护下拉框里的选项（如镀金颜色、来料类别） |

> **提示**：每个人的账号权限不同，您看到的菜单和按钮可能比上面列的少，也可能多。看不到某个功能说明您没有该权限，需要请联系管理员开通。

每个管理页面的操作方式都差不多：**上方是搜索条件，中间是【搜索】【新增】【删除】按钮，下方是数据表格**。页面底部可以翻页、选择每页显示条数。

## 五、首页统计报表

首页是给管理人员看的数据汇总，**不需要录入任何东西，只需要选择条件查看**。

### 操作步骤

1. 点击左侧菜单 **【首页】**。
2. 在上方选择 **开始月份** 和 **结束月份**（比如 2026-01 至 2026-08）。
3. 如需要，再选择某个 **镀金颜色** 进行筛选；不选则显示全部。
4. 页面会显示三块统计内容：
   - **入库统计**：这段时间收到货的情况
   - **订单明细统计**：订单数量、总额（元）
   - **返修统计**：返镀件个数、返修率
5. 点击 **【导出】** 可以把统计结果保存为 Excel 表格。

## 六、客户公司管理

这里维护客户名单。**只有在名单里的客户，录入订单时才能选到。**

### 1. 新增客户

1. 点击左侧菜单 **【客户公司】**。
2. 点击 **【新增】** 按钮。
3. 填写 **客户名称**，点击提交。
4. 系统会自动生成客户编号。

### 2. 查找客户

在搜索框输入客户名称或编号，点击 **【搜索】**。

### 3. 删除客户

先在表格左侧勾选该客户，再点 **【删除】**。
**删除前请确认该客户名下没有订单，否则历史数据会对不上，拿不准就先问管理员。**

### 4. 用户管理和角色管理（管理员操作）

点击某个客户所在行的 **【详情】**，进入该客户的信息页，里面有两个标签页：

- **用户管理**：给员工开设账号（姓名、工号）、重置密码、**锁定/解锁**账号、配置角色权限。
- **角色管理**：设置不同角色能看哪些菜单、能点哪些按钮。

> 普通录入员一般不用管这块，由管理员负责。

## 七、字典管理（选项维护）

系统里很多下拉框的选项（比如"来料类别"、"镀金颜色"、"烤厅"）都集中在这里维护。

### 什么时候需要用它？

- 出现了一种新的镀金颜色，但下拉框里选不到；
- 来料类别需要增加或修改名称。

### 操作步骤

1. 点击左侧菜单 **【字典管理】**。
2. 找到要改的类别（如"镀金颜色"）。
3. 点击 **【新增】** 添加一个新选项；点击某一行的编辑图标可以改名；勾选后点 **【删除】** 可以删掉。

> **注意**：修改字典会影响到所有用到该选项的页面。已经被历史记录使用过的选项**不建议删除**，否则老数据可能显示不出来。拿不准时请先问管理员。

## 八、订单管理（建立订单）

一张"订单"相当于一个文件夹，里面装着多条"订单明细"。**先建订单，再录明细。**

### 1. 新增订单

1. 点击左侧菜单 **【订单管理】**。
2. 点击 **【新增】** 按钮，右侧弹出填写窗口。
3. 填写内容：
   - **客户名称**（下拉选择，客户要先在"客户公司"里建好）
   - **PO号**（客户提供订单号，没有可不填）
   - **交货时间**（点选日期）
   - **编号**：**不用填！提交后系统自动生成。**
   - **组件总数 / 订单明细数**：**不用填！** 加入订单明细后系统自动汇总。
4. 点击 **【提交】**。

### 2. 查看订单内的明细

在订单列表中，点击某行最左侧的 **展开箭头（▶）**，可以看到这个订单里的所有订单明细。

### 3. 修改、删除订单

- **修改**：点击该行操作列的 **【详情】** 按钮，修改后提交。
- **删除**：勾选该行，点击 **【删除】**。**订单里已经有明细时不要随意删除订单。**

---

## 九、订单明细管理

这是录入工作中用得最多的页面。每一条明细代表订单中的一个部件。

### 1. 新增订单明细

1. 点击左侧菜单 **【订单明细】**。
2. 点击 **【新增】** 按钮，右侧弹出填写窗口。
3. 逐项填写：

| 填写项 | 怎么填 |
|---|---|
| 所属订单 | 输入订单编号搜一下，选出来；也可以留空先录 |
| 客户名称 | 下拉选择 |
| 订单明细图片 | 点中间的 **＋** 号，选择产品图片（图片请小于 10MB） |
| PO号 | 输入时系统会自动提示以前填过的，可选用 |
| ITEM号 | 输入时会自动提示历史记录 |
| 部件 | 输入时会自动提示历史记录 |
| 数量 | 填数字 |
| 每套组件数量 | 填数字 |
| 组件总数量 | 一般自动算出，也可手动调整 |
| 交货时间 | 点选日期 |
| 单价 | 填数字 |
| 合计 | **自动计算，不用填**（= 数量 × 单价） |

4. 点击 **【提交】**。填错了想清空重来，点 **【重置】**。

### 2. 修改订单明细

1. 在表格中找到要改的那一行，点击操作列的 **【详情】**（铅笔图标）按钮。
2. 修改内容后点击 **【提交修改】**。

### 3. 删除订单明细

勾选要删的行（一行最前面的方框打勾），点击上方 **【删除】** 按钮。

> **删除前请三思**：如果这条明细已经有入库或出库记录，删除会造成库存数据混乱。拿不准请先问管理员。

### 4. 查找订单明细

上方提供多种搜索条件，可以单独用，也可以组合用：

- 按 **客户名称**、**PO号**、**ITEM号**、**明细编号** 查找
- 按 **入库编号**、**出库编号**、**来料类别** 查找
- 按 **时间范围** 查找（先选"时间类别"：明细时间 / 入库时间 / 出库时间，再选起止日期）

填好条件后点 **【搜索】**。想看全部数据就清空条件再搜一次。

### 5. 导出和打印

- **【导出】**：把当前查到的数据保存成 Excel 文件。
- **【打印】**：直接打印当前列表，打印页底部会自动带上公司名称和日期。

### 6. 看每条明细的出入库记录

点击某行最左侧的 **展开箭头（▶）**，能看到这条明细对应的所有入库、出库记录，方便对账。

### 7. 表格里的红色数字是什么意思？

表格中有几列数字**变红**，是系统在提醒您数量对不上：

- **"已入库组件总数"变红**：入库的数量超过了订单数量，可能多录了入库；
- **"已出库良品组件总数"变红**：出库数量超过了入库数量，可能录重了出库。

看到红色数字请先核对最近的录入记录，确认是否录错。

## 十、入库管理

客户把货送来时，在这里登记。

### 1. 新增入库

1. 点击左侧菜单 **【入库管理】**。
2. 点击 **【新增】** 按钮，弹出填写窗口。
3. 逐项填写：

| 填写项 | 怎么填 |
|---|---|
| 订单明细编号 | 输入编号搜索并选中对应的订单明细 |
| 客户名称 | 选择客户 |
| 来料类别 | 下拉选择（选项由"字典管理"维护） |
| 入库镀金颜色 | 下拉选择 |
| 烤厅 | 下拉选择 |
| 组件数 | 填本次收到的数量 |
| 单位 | 下拉选择：个 / 千克 / 克 |
| 数量说明 | 备注文字，比如特殊情况说明 |
| 不良原因 / 返镀原因 | 如有不良品或返镀，填写原因 |
| 产品图片 | 上传图片（小于 10MB） |

4. 点击 **【提交】**，系统自动生成入库编号。

### 2. 修改、删除入库记录

- **修改**：点击该行 **【详情】** 按钮，改完提交。
- **删除**：勾选该行后点 **【删除】**。**注意：如果这条入库已经做出库了，请勿删除，会造成出库记录找不到对应的入库。**

### 3. 查找、导出、打印

和订单明细页面一样：填好上方搜索条件点 **【搜索】**；点 **【导出】** 存 Excel；点 **【打印】** 打印清单。

## 十一、出库管理

货物发给客户时，在这里登记。

### 1. 新增出库

1. 点击左侧菜单 **【出库管理】**。
2. 点击 **【新增】** 按钮，弹出填写窗口。
3. 逐项填写：

| 填写项 | 怎么填 |
|---|---|
| 入库编号 | 输入编号搜索并选中对应的入库记录（出库必须挂在某次入库上） |
| 出库类型 | 下拉选择，常用类型有：**良品、不良、白金出库、硫酸铜出库、返回挑面、检查面不良返镀、镀金不良返镀、电烤厅、检查完加金、打底、其他** |
| 镀金颜色 | 下拉选择 |
| 烤厅 | 下拉选择 |
| 组件数 | 填本次发出的数量 |
| 数量说明 | 备注文字 |
| 出库图片 | 可上传出库时的照片 |

4. 点击 **【提交】**，系统自动生成出库编号。

### 2. 出库类型怎么选？（速记）

- 正常合格交货 → **良品**
- 有问题退回/报废类 → **不良**
- 需要返工重镀 → 各种 **返镀** 类型
- 特殊用途（白金、硫酸铜等） → 对应选项
- 实在不确定 → 选 **其他**，并在数量说明里写清楚，事后与主管确认

### 3. 修改、删除、查找、导出、打印

操作方式与入库管理完全相同。

## 十二、日常工作的标准流程

以一票正常的业务为例，从头到尾的操作顺序是：

```
① 建客户（只需一次，已有就跳过）
        ↓
② 建订单（订单管理页）
        ↓
③ 录订单明细（订单明细页）——每个部件录一条
        ↓
④ 客户送货来 → 入库管理 → 新增入库
        ↓
⑤ 发货给客户 → 出库管理 → 新增出库（选择类型：良品等）
        ↓
⑥ 日常核对：订单明细页展开 ▶ 查看出入库记录，
   发现红色数字及时核对更正
        ↓
⑦ 月底：首页看统计报表，或各页面【导出】Excel 存档
```

**四句口诀：先建订单再录明细；先入库才能出库；编号自动生成不用填；红色数字要核对。**

## 十三、常见问题解答

**问：我看不到某个菜单 / 某个按钮，是系统坏了吗？**
答：不是。每个人的账号权限不同，看不到就是没有权限。请联系管理员开通。

**问：点提交后没反应或提示出错？**
答：先检查带红星或必填的项目是否都填了，特别是数字栏里不要输入汉字、空格或全角字符。

**问：表格里的数字变成红色了怎么办？**
答：红色表示数量超出（入库超过订单量、或出库超过入库量）。请核对最近的记录是否录重、录多。

**问：编号要自己编吗？**
答：不用。订单编号、明细编号、入库编号、出库编号全部由系统自动生成。

**问：合计金额要自己算吗？**
答：不用。数量和单价填好后系统自动算。

**问：图片上传失败？**
答：请确认图片小于 10MB，且是常见的 jpg/png 格式。手机拍的照片太大时，可先压缩再传。

**问：页面顶部出现红色提示"网络异常"？**
答：说明电脑断网或网络不稳。请检查网线/WiFi，关闭浏览器重新打开再试。如果电脑上开了 VPN 或代理软件，请关闭后再试。

**问：密码忘了怎么办？**
答：联系管理员，由管理员在"客户公司 → 详情 → 用户管理"里为您重置密码。

**问：改完密码后进不去了？**
答：修改密码成功后系统会自动退出，请用**新密码**重新登录。

**问：删错了数据怎么办？**
答：立即停止操作并联系管理员，说明大概的时间和内容。**删除操作无法自己恢复**，所以删除前务必确认。

**问：换了一台电脑，数据还在吗？**
答：在。所有数据都保存在服务器上，换电脑、换浏览器都不影响，用您的账号登录即可。
